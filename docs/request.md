依頼したい目標は、文字エンコーディング判定処理の世界言語への対応です。

EncodingProbeの文字エンコーディング判定は、Native処理とUtfUnknown処理の二つの系統で行っており、現在はデフォルトでまずNative処理で解析して、不明だったらUtfUnknown処理で判定します。
しかし、この処理系だと、英語・日本語・韓国語・繁体字中国語・簡体字中国語では良いのですが、それら以外の言語だと誤判定が起きる可能性があります。

Native処理は英語・日本語・韓国語・繁体字中国語・簡体字中国語しか解析できないので、カルチャーがそれら以外の言語圏の場合は、Unicodeの解析以外は必ずしもNative処理は必要無いのです。

そこで、既にカルチャーの識別処理が組み込まれているので、Native処理が非対応のカルチャー情報の場合は、Unicodeの解析以外はスキップして、Unicode以外はUtfUnknown処理で文字エンコーディングを解析するように、改修して欲しいです。

Unicodeの解析処理はどのカルチャーでも実行して欲しいです。
UtfUnknown処理は BOM無しのUTF-16,UTF-32 に非対応だからです。

ソースコードを解析して、修正方法を検討してください。
