# EncodingProbe-1.2.0-開発実装の依頼

カレントフォルダーの配下には、クラスライブラリの`EncodingProbe`と、PowerShellコマンドレットの`EncodingProbe.PowerShell`が入っています。

クラスライブラリの方は、既に 1.2.0 用の改修が終わっています。リリースはしていません。

現在のカレントフォルダーのPowerShellコマンドレットのプロジェクトは 1.1.0 版で、既にリリースされている物です。

このコマンドレットに、バージョン 1.2.0 の新規機能追加を行います。

バージョン 1.2.0 の追加仕様は、`EncodingProbe-1.2.0-仕様書.md`の文書に記載しています。

仕様書を参考に、`EncodingProbe.PowerShell`の新機能の開発と実装をお願いします。

作業が完了したら、開発用のブランチに`commit`と`push`をしておいてください。

まだ、`master`ブランチにマージはしません。

ソースのバージョン番号などは、クラスライブラリもコマンドレットも`1.2.0`に更新しておいてください。

リリースは、まだしないでください。
