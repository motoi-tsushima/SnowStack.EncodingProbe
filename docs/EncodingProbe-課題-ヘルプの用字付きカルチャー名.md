# 課題 — PowerShell 7 で用字付きのカルチャー名のヘルプが en-US になる

- 起票日: 2026-09-23
- 起票の経緯: `EncodingProbe-1.2.0-依頼-第三次修正_香港ロケール.md` 6 章の 1
- 状態: **未着手**
- 対象: MAML ヘルプの言語フォルダー（`SnowStack.EncodingProbe.PowerShell/<カルチャー>/`）と配布物

---

## 1. 現象

UI カルチャーが次のとき、`Get-Help` の表示言語が PS 5.1 と PS 7 で異なる。

| UI カルチャー | PS 5.1（net48 / NLS） | PS 7（net10.0 / ICU） |
|---|---|---|
| `zh-Hant-TW` | 繁体字（zh-TW フォルダー） | **en-US** |
| `zh-Hant-HK` | 繁体字（zh-HK フォルダー） | **en-US** |
| `zh-Hant-MO` | 繁体字（zh-MO フォルダー） | **en-US** |
| `zh_HK` | 繁体字（zh-HK フォルダー） | **en-US** |

`zh-Hant-TW` は 1.2.0 より前からこの状態である。
`zh-Hant-HK` / `zh-Hant-MO` / `zh_HK` は、1.2.0 第三次修正で `zh-HK` / `zh-MO` フォルダーを足したことで、
PS 5.1 だけが繁体字になるという形で差が現れた。

メッセージ（`MessageCatalog`）はサブタグ分解で言語を選ぶため、両ホストとも繁体字になり、この問題は無い。

## 2. 原因

`Get-Help` は「UI カルチャー名と同名のフォルダー → 親カルチャーのフォルダー → en-US」の順でヘルプを探す。
この探索の仕組みは両ホストで同じである。差は、カルチャー名そのものが NLS と ICU で異なることから生じる。

- NLS（PS 5.1）は `zh-Hant-HK` → `zh-HK`、`zh-Hant-TW` → `zh-TW`、`zh_HK` → `zh-HK` と名前を正規化する
- ICU（PS 7）は正規化しない。`zh-Hant-HK` の親は `zh-Hant`、`zh_HK` の親は `zh` である

リポジトリには `zh-Hant` / `zh` のフォルダーを置いていないので、PS 7 では en-US に落ちる。

## 3. 対処の選択肢

1.2.0 香港ローカライズの調査（2026-09-23、`1.2.0-香港ローカライズ-調査報告.md` 1.3 節。リポジトリには含めていない）で比較した構成案を引用する。

| 構成 | zh-HK | zh-MO | zh-Hant-HK（PS 7） | zh-Hant-TW（PS 7） | 備考 |
|---|---|---|---|---|---|
| zh-HK・zh-MO を追加 | 香港版 | 香港版 | en-US | en-US | 最小。PS 7 の用字付きの名前は英語に落ちる（**1.2.0 で採用**） |
| 上に加えて zh-Hant-HK・zh-Hant-MO・zh-Hant-TW を追加 | 香港版 | 香港版 | 香港版 | 台湾版 | 両ホストで一致する。フォルダーが 5 つ増える |
| zh-Hant（親）を置く | 置いた内容 | 置いた内容 | 置いた内容 | 置いた内容 | 台湾版と香港版を分けられない。CLAUDE.md の方針（親カルチャー名は置かない）に反する |

「香港版」は 1.2.0 では台湾版と同じ内容である（B 案）。

2 番目の案では、`zh-Hant-HK` / `zh-Hant-MO` / `zh-Hant-TW` の 3 フォルダーを足すことになる。
配布物では `core\` と `desktop\` の下に足すので、コピー先は 14 か所から 20 か所になる。
`zh_HK` は ICU での親が `zh` なので、この案でも en-US のままである（`zh_HK` という名前のフォルダーを置くかどうかは別途判断）。

## 4. 判断材料

- これらの UI カルチャーが実際に使われる場面は限られる。
  Windows が報告する UI カルチャーは `zh-TW` / `zh-HK` 形式であり、用字付きの名前は明示的に設定した場合に現れる
- 一方で「PS 5.1 と 7.x で同じ結果になる」ことは本モジュールの存在意義であり、
  PSCompat では現在 `zh_HK` のヘルプを比較対象から外している（`tests/PSCompat/ProbedCompatScenarios.ps1` の「香港ロケールのメッセージとヘルプ」の節）
- フォルダーを増やす場合、`MamlHelpTests` の `Cultures` と、zh-TW との一致を検査する対象にも足す
- 配布のコピー先が増える問題は `EncodingProbe-課題-ヘルプ配布の自動化.md` と合わせて検討するとよい
